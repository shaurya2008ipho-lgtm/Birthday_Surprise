# A Birthday Surprise for Vanshika 🎂

A responsive, animated birthday website made with plain HTML, CSS, and JavaScript. It uses no build tools and has no required package installs.

## Run it on your computer
1. Extract `Vanshika_Birthday_Surprise.zip`.
2. Open `index.html` in Chrome, Edge, Firefox, or Safari.
3. Click the hanging gift and enjoy the reveal. Scroll down for the personal birthday letter.

The page imports Google Fonts when internet access is available; the website otherwise falls back to system fonts and still works.

## Publish it as a shareable link
### GitHub Pages
1. Create a new GitHub repository (for example, `vanshika-birthday`).
2. Upload `index.html`, `styles.css`, and `script.js` (you can also upload this README).
3. Open **Settings → Pages**.
4. Under the build/deployment section, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the page, then copy the public URL and send it to Vanshika.

### Netlify Drop
1. Open Netlify's manual deploy/drop page in your browser.
2. Extract the ZIP and drag the `vanshika_birthday_site` folder (or its contents) into the drop area.
3. Copy the generated public URL and share it with her.

## Personalisation
- The main birthday headline and full letter are in `index.html`.
- Colors, layout, and animation timing are in `styles.css`.
- Gift interaction and confetti are in `script.js`.

Tip: test the published link on your phone before sending it, so the surprise opens the way you expect.
